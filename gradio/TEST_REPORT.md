## 建议课程演示前的手工验收

1. 打开本机页面，点英文示例，选择中文翻译并识别；核对原文、译文、下载。
2. 播放音频并暂停，确认字幕停住；拖回前面确认文字回退；播放至结束再重播。
3. 分别点击中文、日文、西班牙文示例识别，核对检测语种。
4. 授权本机页面麦克风，录制一段包含人声的短句，停止、试听、识别。
5. 在没有 NVIDIA GPU 的本机选择 GPU，确认明确提示；切回 CPU 正常识别。
6. 有 CUDA 的设备上另外验证 GPU float16 实际推理和 CPU/GPU 切换；本机无法完成这两项。

## 已知限制

只有四语言的短样本自动测试，不能替代完整质量或压力测试。ASR 会误识别，语言置信度不是转写准确率。中日文字符同步使用词内插值；译文仅按源片段出现。翻译模型质量较有限，日西语中转会放大误差。不支持其他源语种中文翻译。临时文件需长期运行时自行管理。具体部署与实现见 `gradio/README.md`。
